# AntsNet Split Strategy for ants_v3_mixedscale_e01

Status: proposal only. Do not materialize AntsNet into TRAIN/VAL without a separate approval step.

## Audited Source

- Roboflow Universe project: `antsnet/antsnet`
- Audited version: `v14`
- Export format: YOLOv8 object detection
- Images: 997
- Annotations: 6751
- License reported by Roboflow/export: MIT
- Preprocessing/augmentation reported by Roboflow: none / none

## Do Not Reuse Original Splits Blindly

Version `v14` is 100% train, while `v13`/`v12` used a train/valid split. Those splits are Roboflow source splits, not FormicAI leakage-safe splits. If AntsNet is incorporated later, split by leakage groups first, then by model role.

## Leakage Groups

Use these group levels, in order of preference:

1. Explicit source/provenance ID, if it can be recovered outside the YOLO export.
2. Filename family key, generated by stripping the Roboflow `.rf.<hash>` suffix and collapsing repeated numbered series.
3. Species/caste family where filename provenance is unavailable.
4. Perceptual near-duplicate component from local dHash audit.

Never split images from the same exact duplicate hash or strong near-duplicate family across train and validation.

## Recommended Role

For `ants_v3_mixedscale_e01`, AntsNet should be treated as a candidate public source for manual review/remapping, not as ready-to-train YOLO labels. Adult `queen_*` / `worker_*` classes are promising for adult-ant coverage, but brood classes must remain NOT-ant metadata and taxonomic-only labels need human review.

## Suggested Use

- Start with the candidate subset in `datasets/ants_v3_design/antsnet_candidate_subset.json`.
- Keep it capped at 50-100 images for the first review round.
- Prioritize queen/large-scale, majors/minors, brood context, and diverse backgrounds.
- Re-label selected images manually under FormicAI policy before training.

## Benchmark Hygiene

Do not use AntsNet to tune thresholds against frozen benchmarks. If AntsNet becomes part of TRAIN, keep ant4 and any future own-colony validation/test videos separated by source and time.
